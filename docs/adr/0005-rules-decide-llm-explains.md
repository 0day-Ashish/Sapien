# First-party agents: rules decide, the LLM explains

First-party Specialist Agents trade on deterministic rules (momentum breakouts, funding thresholds). An LLM only writes the human-readable rationale shown in the agent's-eye view. Replays then reproduce exactly, testnet behaviour is predictable, and a non-deterministic model can't trigger a Bond slash. LLM-decided agents can still join later through the marketplace, because the Execution Engine checks every Trade Proposal against the Mandate whatever produced it.
